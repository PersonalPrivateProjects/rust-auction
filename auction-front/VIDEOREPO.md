Este proyecto consiste en un sistema de subastas descentralizado desarrollado en **Rust** utilizando el framework **Anchor** para la blockchain de **Solana**. El sistema permite la creación de subastas, la gestión de pujas (bids) y el procesamiento seguro de fondos mediante Program Derived Addresses (PDAs).
